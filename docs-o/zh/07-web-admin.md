# 07 — Web 管理控制台（`rtdb-admin`）

`rtdb-admin` 是一个 Vue 3 单页应用。它**只消费公开的 REST API**，因此有两种部署方式：

| 形态 | 方式 | 适用场景 |
| ---- | ---- | -------- |
| **内置**（默认） | 由 `rtdb-server` 在 `http://<host>:<port>/admin/` 提供 | 单实例，最简配置 |
| **独立部署** | 把 `packages/admin/dist` 部署到任意静态 Web 服务器；在界面中配置实例地址与令牌 | 一个控制台管理多个实例 |

---

## 1. 构建

```bash
cd ss-rtdb/src
npm install                          # 若尚未执行
npm run build --workspace @ss/rtdb-admin
```

产物：`packages/admin/dist/`。构建使用 `base: './'`，因此产物可放在任意路径下工作。

不构建也不影响服务运行，只是 `/admin` 会返回 404。

## 2. 内置形态

默认配置已开启：

```json
{ "admin": { "enabled": true, "staticDir": "" } }
```

- `staticDir: ""` → 使用内置的 `packages/admin/dist` 目录。
- 打开 <http://127.0.0.1:6180/admin/> —— **结尾的斜杠很重要**；`/admin` 会 301 跳转到 `/admin/`，
  这样相对路径的静态资源才能正确解析。直接访问站点根路径 `/` 会 **302 跳转到 `/admin/`**
  （`admin.enabled=false` 时根路径仍返回 404）。
- 打开控制台后先是**全屏登录页**，登录成功后才显示主界面（侧边栏 + 顶栏 + 面板），
  与一般管理系统的使用方式一致；`auth.enabled = true`（默认）时用用户名 + 口令登录
  （`POST /api/v1/auth/login` 换取 API 令牌）。首次启动的服务会自动创建默认管理员
  `admin` / `ss-rtdb`（见 [02 — 配置](./02-configuration.md) §6.4），表单已预填这两个值，
  点一次 **Sign in** 即可进入。
- 登录页表单里可直接填写**服务地址**（留空 = 与页面同源的内置形态）；已有令牌时可展开
  **Use an existing token instead** 粘贴令牌，控制台会先调用 `GET /api/v1/auth/session` 校验再启用。
- 主界面右下角（侧边栏底部）显示当前账号与角色、**Connection**（连接设置对话框：服务地址 +
  令牌，留空令牌即退出登录）与 **Sign out**（吊销令牌）。
- 浏览器只保存令牌（`localStorage`），**口令不会被存储**（随登录表单一起销毁）。
- 控制台没有独立鉴权：它调用的是同一套 REST API，每次请求都带同一个令牌，权限域完全一致。
- 若实例显式关闭了鉴权（`auth.enabled = false`），匿名 `GET /api/v1/auth/session` 会直接返回身份，
  控制台据此**免登录**进入主界面（侧边栏账号处标注 `open access`），不会卡在一个永远无法成功的登录页。

如需关闭（例如改用独立部署形态）：

```json
{ "admin": { "enabled": false } }
```

如需从其他位置提供自己的构建产物：

```json
{ "admin": { "enabled": true, "staticDir": "/opt/rtdb-admin/dist" } }
```

## 3. 独立部署形态

1. 构建（`npm run build --workspace @ss/rtdb-admin`），并把 `packages/admin/dist/` 上传到你的
   静态主机（nginx、带静态网站托管的对象存储等）。
2. 打开站点，在登录页的**服务地址**中填写 **API 基址** —— 例如 `https://rtdb.example.com`。
   **留空**表示与页面同源（即内置模式的行为）；登录页也可先点 **Test connection** 验证连通。
3. 用 **Sign in** 登录（用户名 + 口令 → 令牌），或展开 **Use an existing token instead** 粘贴在
   别处签发的令牌（使用“访问控制”面板需要 `admin` 权限域）。
4. 登录后可在侧边栏底部 **Connection** 对话框中调整基址或令牌（新令牌会先校验）；两者自动保存在
   浏览器本地存储中 —— 从不上传服务端 —— 因此每位运维人员各自保管自己的凭据。
5. 在服务实例上允许控制台所在来源：

```json
{
  "host": "0.0.0.0",
  "cors": { "allowedOrigins": ["https://rtdb-admin.example.com"] },
  "auth": { "enabled": true, "mode": "token" }
}
```

> CORS **需显式开启且默认关闭**。非回环监听还必须保持 `auth.enabled = true`，否则启动会失败。

由于控制台是纯静态站点、没有服务端状态，你可以把一份副本提供给多位运维人员，
各自指向自己所管理的实例。

## 4. 面板

主界面采用**左侧固定侧边栏 + 顶栏 + 内容区**的布局：侧边栏按「总览（状态）· 数据（数据库 / 指标 /
备份）· 安全（访问控制）」分组导航，底部是账号、**Connection** 与 **Sign out**；顶栏显示当前面板名、
接口文档入口与语言切换。窄屏（≤900px）下侧边栏折叠为顶部横向导航条，表格改为横向滚动，不再挤压列宽。

| 面板 | 显示 / 功能 |
| ---- | ----------- |
| **状态** | 按 **总览（运行时长 / 写入吞吐 / 数据库数 / 指标数 / 缓冲点数，大号 KPI）→ 写入与 WAL → 存储与缓存 → 运行资源 → 查询延迟** 分组展示连接状态、**进程 CPU 占用（单核 % 与整机占比）、常驻内存 / 内存占用率 / 堆使用率**、写入与查询速率、WAL 积压、缓存命中率、延迟分位 |
| **数据库** | 分类展示：(1) 位置 / 大小 / 状态 —— 目录（相对服务运行目录）、磁盘占用（段 / 索引 / WAL 细分）、保留策略覆盖值与可展开的按天明细；(2) 按数据库名筛选，筛选结果即下方清单表。保留天数可就地修改，并通过 `GET /api/v1/databases/{db}` 读回 |
| **指标** | **单卡片双 tab**：`Metric inventory`（指标清单）与 `Range preview`（范围预览）。点清单行的 `View`（查看）打开**模态查询对话框**（不再切 tab）：时间段默认**当天**（本地 00:00:00 → 当前时刻），沿用同一个「时间段」控件（快捷区间、按天选择、精确到秒、全部 = 该指标全区间），**打开即自动查询**（无需再点按钮；一天的秒级采样有 86 400 点，所以结果**默认以列表分页展示，每页 20 条**，可选 20 / 50 / 100 / 200，底部翻页条含 `第 a–b 条，共 n 条`），点**查询**可重新查询 `POST /api/v1/query/range`；**导出 CSV** 下载的是**全部**返回点（与分页无关，原始毫秒 epoch + 带 UTC 偏移的本地时间，UTF-8 BOM + CRLF + RFC 4180 引用）。清单含首/末时间戳，另有两列**实时值**与**更新时间**（当前页所有行用**一次** `POST /api/v1/query/last-batch` 取回最新点）；工具栏默认**每 5 秒自动刷新**当前页（切到范围预览或浏览器标签页隐藏时暂停），也可点**刷新实时值**立即读取；此前刷新过的页保留各自的值。1 万指标的库按**分页**展示（每页 50 / 100 / 200 / 500 条，默认 100），底部有翻页条（`«` / 上一页 / 下一页 / `»`、`第 x / y 页`、`第 a–b 条，共 n 条`）；切换页码或每页条数时，若实时值已加载过则自动刷新新页。已不存在"一个指标一次请求"的路径，表格也不会一次性渲染整个目录。预览区的变量为**下拉选择**（combobox），切换后自动重绘。时间区间合并为**一个「时间段」控件**（Grafana 风格）：触发器直接显示当前范围 `起 → 止`，点开弹层后可选快捷区间（5 分钟 / 15 分钟 / 1 小时 / 6 小时 / 24 小时 / 7 天 / 全部 = 该指标全区间）或精确到秒地填写起止时间，快捷项即时生效并自动查询，手工填写需点「应用」。弹层同时提供**按天选择**（起始日 / 结束日，本地时区、含首末两天）：选起始日自动填 `00:00:00`、选结束日自动填 `23:59:59`，与精确时间字段双向联动（改时间会回写日期），只选一侧时另一侧自动补齐；范围为空或起晚于止时点「应用」会就地提示而不发起查询。查询可选原始点（`query/range`）、窗口聚合（`query/aggregate`，算子 `avg`/`sum`/`min`/`max`/`count`/`last`）或插值重采样（`query/at`，`step` / `linear`）——**聚合与插值都由同一个「时间窗口」（秒/分/时）驱动**：聚合按窗口分桶，插值以窗口为步长（起点、起点+窗口、…）采样；条数上限仅对原始点查询生效。控件下方有两行提示：原始点直接连线、不做插值（缺失段会显示为斜坡），`avg` 为时间加权平均、窗口外相邻点做线性插值，并给出实测采样间隔中位数与最大缺口。当前预览可导出 `*.xls`（Excel 2003 SpreadsheetML，保留数值/布尔/字符串类型）。**指标清单**（`GET /api/v1/metrics/{db}`）可一键**导出 CSV**：列为数据库、指标名、数据类型、首个点、最后点（各含「本地时间 + UTC 偏移」文本列与毫秒 epoch 数值列），UTF-8 BOM + CRLF，指标名含逗号/引号/换行时按 RFC 4180 引用。时间列格式为 `YYYY-MM-DD HH:mm:ss (UTC+08:00)`：末尾偏移使 Excel/WPS 不再把单元格自动识别成日期，因此秒不会被隐藏、时区也一目了然 |
| **备份** | 触发备份并显示结果：可填服务端目标目录，时间段改用与指标面板相同的**「时间段」控件**（按天模式）：触发器显示 `起始日 → 结束日`，弹层提供快捷项（今天 / 3 天 / 7 天 / 30 天 / 不限时间段）与**起始日 / 结束日**两个日期选择（按天粒度、服务端本地时区、含首末），任一侧留空表示该侧不限；两侧都留空（或选「不限时间段」）即整库备份。完成后展示模式（整库 = 还原时替换 / 时间段 = 还原时按天合并）、实际时间范围与天数、文件数与总字节 |
| **访问控制** | 用户（创建 / 改密 / 改角色 / 启停 / 删除）与 API 令牌（签发 / 吊销；明文只显示一次）。令牌列表带**刷新**按钮，**已失效的 `console login` 登录会话默认隐藏**（勾选「显示已失效的登录会话」可查看），并逐条显示最后访问的数据库、最后访问时间与当前写入速度（点/s + 负载字节/s，来自 `GET /api/v1/admin/tokens`），表格首行固定为**静态令牌**（`config-token`，即 `rtdb.token`；Smart Site 演示客户端的写入计在这里）；**写入速度列紧随令牌 id**（id 缩写显示，完整值见悬浮提示），无需横向滚动即可看到，面板每 5 秒自动重读一次端点保持速率实时；面板同时提示：令牌是服务端凭据，关闭客户端不会吊销 |

状态数据来自 `GET /api/v1/status`；其余均对应 [04 — HTTP API](./04-http-api.md) 中记录的端点。

顶栏右侧还有一个 **接口文档** 入口：在新标签页打开服务端内置的 `/api/docs`。其地址跟随已保存的
API 基址 —— 内建形态下是相对路径，独立部署形态下是 `<远端实例>/api/docs` —— 因此始终描述控制台
当前连接的实例。参考页面由服务端按路由表生成且公开（无需登录），详见
[04 — HTTP API](./04-http-api.md) §8.1。

## 5. 界面语言

控制台内置两种语言，默认 **英文**：

| 语言 | 覆盖范围 | 说明 |
| ---- | -------- | ---- |
| `en`（默认） | 全部界面文案 | 词条基准（`packages/admin/src/locales/en.ts`） |
| `zh` | 全部界面文案 | 按 `Record<MessageKey, string>` 约束（`packages/admin/src/locales/zh.ts`），漏译会导致构建失败 |

- 顶栏按钮（登录页为右上角）在英文界面显示 `中文`、在中文界面显示 `EN`，点击即切换。
- 选择保存在 `localStorage` 的 `rtdbAdminLocale` 键中，刷新后保持；`<html lang>` 与页面标题同步切换。
- 切换语言完全在本地完成：不会向服务端发送任何请求，已经显示在界面上的提示会按新语言重新渲染。
- 新增界面文案必须同时补齐两份词典（AGENTS.md §4 第 12 条）：只有英文键、没有中文键时，
  `npm run typecheck --workspace @ss/rtdb-admin`（`npm run build` 也会执行）会直接报错，两份词典不会漂移。
- 词条中可包含 `{placeholder}` 占位段（如 `{database}`、`{days}`、`{time}`），由 `t()` 用面板传入的值填充。

## 6. 故障排查

| 现象 | 原因 | 处理 |
| ---- | ---- | ---- |
| `/admin` 返回 404 | 未构建 admin 产物，或 `admin.enabled: false` | 构建 admin 工作区；启用 `admin` |
| 页面能打开但静态资源 404 | 通过自定义代理访问时用了不带斜杠的 `/admin` | 使用 `/admin/`；保留 301 跳转 |
| 访问根路径 `/` 返回 `E_NOT_FOUND: Unregistered route: /` | 旧版本服务端没有根路径跳转，或 `admin.enabled=false` | 升级到带根路径跳转的版本；关闭内建控制台时访问 `/admin/` 并自行提供静态站点 |
| 控制台显示 `E_AUTH` / `401` | 未登录、令牌失效，或匿名访问需要凭据的端点 | 用 **Sign in** 登录；或粘贴有效令牌；检查 `rtdb.token` |
| 登录返回 `401 E_AUTH` | 用户名 / 口令错误，或该实例的用户目录非空且无此用户 | 首启实例用 `admin` / `ss-rtdb`；其余用运维提供的账号 |
| 忘记默认管理员口令 | 口令只存 scrypt 哈希，无法找回 | 用管理员令牌 `PUT /api/v1/admin/users/admin` 改密；或停服后删除 `rtdb-users.json` 再启动（空目录会重建默认管理员） |
| 独立部署的控制台连不上 API | CORS 未开启，或来源未加入白名单 | 设置 `cors.allowedOrigins` 并重启 |
| 访问控制面板返回 403 | 令牌角色不是 `admin` | 签发 `admin` 角色的令牌 |
| 刷新后一直停在登录页 | 本地令牌已失效（`GET /api/v1/auth/session` 返回 401），控制台已自动清除 | 重新登录，或在登录页展开令牌输入框粘贴新令牌 |
| 保存连接设置后回到登录页 | 在 Connection 对话框中把令牌留空保存（等同退出登录） | 重新登录，或在对话框中填写有效令牌 |
